# Support

PayTrue is a volunteer-maintained, **pre-alpha** open-source project. There is no commercial support and no service-level agreement.

| You want to... | Do this |
|---|---|
| Report a **security vulnerability** | Not a public issue: [SECURITY](SECURITY.md) |
| Report a bug in the code, the tools or the documentation | Open an issue with the **bug report** template: what you ran, what you expected, what happened, the commit, your OS and Node, Python and Foundry versions |
| Propose a feature or a change to the protocol | Open an issue with the **feature request** template; a protocol change begins in the specification ([CONTRIBUTING](CONTRIBUTING.md)) |
| Ask how to use something | Read the [documentation](docs/README.md) first, in particular [getting started](docs/getting-started.md), [headless use](docs/headless.md) and [domains](docs/domains.md); then open an issue labelled `question` |
| Ask about licensing, the name or trademarks | [Licensing](docs/licensing.md), [TRADEMARK](TRADEMARK.md); then an issue titled "Licensing" or "Trademark" |
| Run PayTrue in production | You can not yet: [production deployment](docs/production-deployment.md) lists what is missing |

## What helps us help you

- The **exact command** and its **full output**.
- Whether the problem is on the pinned toolchain (`spec/toolchain`) or on your own installation of Foundry or Node.
- A failing test, when you can write one.
- On Windows, whether a port is reserved (`listen EACCES`); the examples and the compose file take free or configurable ports.

## What we cannot do

Debug your private deployment, advise on legal, tax or licensing questions of your business, evaluate a wallet for you, or promise fixes by a date.
