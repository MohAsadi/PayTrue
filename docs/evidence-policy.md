# Evidence policy: public, generated and private

The repository keeps **recorded evidence**: what was built, what ran, what the chains said, what a person signed. Evidence is not approval, and not all of it may be public.
This page separates three classes and says where each lives. The index of the evidence folder is `spec/evidence/README.md`.

## The three classes

| Class | What | Where | In Git? | Rule |
|---|---|---|---|---|
| **Public, curated** | Small records a reader should read: the Permit2 pin, the rebuild record, the findings, the freeze register, the contract report, the cross-language record, ABI and storage snapshots, signed wallet-lab *records* (JSON) | `spec/evidence/**` (not `logs/`) | Yes | Reviewed in pull requests; never edited after review (add a new one) |
| **Public, generated** | Raw logs and reports that the tools produce and that other checks read: forge run logs, fork-run logs, mutation results | `spec/evidence/implementation/logs/`, `*-fork-runs.json`, `contracts-mutation.json` | Yes (large) | Reproducible by the tool that wrote them; never edited by hand; **kept under 50 MiB per file**; compress or move to release assets before a file approaches the limit |
| **Private** | Wallet-lab raw artifacts (screenshots, recordings, network captures, device logs), anything that names a person beyond the signed record, any secret | A private evidence store of the maintainers (`evidence-private/` locally; never committed) | **No** | Published only after a redaction review, by an explicit `git add -f` and a note in the record |

## Why wallet-lab artifacts are private by default

A run record names a tester and a reviewer, their signing addresses, a wallet, a device and a build. Its raw artifacts are screenshots and logs from a real device and often a real account.
They can show balances, addresses, device identifiers, notification text or tokens. People who run the lab are named in `spec/evidence/wallet-lab-kit/people.json`; naming a person in a
public repository needs their consent.

| Rule | Enforced by |
|---|---|
| Raw artifact files (images, recordings, captures, PDFs) under `spec/evidence/wallet-lab/` are ignored by Git | `.gitignore`, and `scripts/repo_hygiene.py` fails if one is tracked |
| A run record (JSON) is public once reviewed and signed by two different registered people | `spec/tools/wallet_lab_verify.py` |
| A record carries the SHA-256 of every raw artifact, so a published record stays checkable against the private store | The record format (`raw[].sha256`) |
| Test keys only, on lab devices; no production secret; funds limited to faucet and canary amounts | `spec/15-wallet-lab-matrix.md` |
| Registering a person in `people.json` is a human act with the person's consent, and no tool adds a name | `spec/evidence/wallet-lab-kit/README.md` |

**Consequence for verification.** `freeze_readiness.py` counts a wallet-lab record only if its artifact checksums match files that sit beside the record. A public clone therefore cannot verify
wallet-lab evidence unless the maintainers publish the redacted artifacts; the maintainers' environment, which holds the private store, can. CI on the public repository does not evaluate the
wallet-lab condition.

## Regenerating evidence

Generated evidence is rewritten by its tool and nothing else: `contracts_tests.py`, `contracts_report.py`, `fork_run.py`, `contracts_mutation.py`, `record_evidence.py`, `impl_report.py`.
Rerun them when the thing they describe changes, and commit the result with the change. A rewritten file keeps its name; a new run is a new record only for wallet-lab evidence.

## Large files

| Limit | Value |
|---|---|
| Fail | 50 MiB per tracked file (GitHub warns at 50 MiB and rejects at 100 MiB) |
| Warn | 20 MiB |
| Toolchain binaries, archives, build output | Never tracked; re-fetched by the pinned toolchain |

`scripts/repo_hygiene.py` implements the limits; the largest tracked file today is `forge-bounds-test.json` (47.3 MiB), a raw forge log. Compressing it needs the evidence tools to read the compressed
form and is **not done**; it is listed as a remaining item.
